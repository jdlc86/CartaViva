## Otros límites relevantes que no se deben maquillar

- Frontera SSH/sudo: argumentos fijos, no shell interpretada, launcher root y entorno cerrado. El lab confirma denegaciones de shell, sudo argv, PTY/forwarding y Docker directo. El root/daemon y la provisión autenticada son TCB. Instalar y verificar launcher/interprete/código **antes** de permitir la cuenta; hashes leídos por JS no son una sandbox frente a root malicioso.
- TAR: dos imágenes por IDs, manifest/OCI/hash de capas/metadata, rechazo de tags ajenos, entradas duplicadas/enlaces y basura. No certificar cualquier variante futura Docker-save ni comportamiento de otro motor/kernel.
- Compose/red: política cerrada, tres servicios, bridges exclusivos, nft semántico, nombres/IDs y reserva de allocations firmada. No inferir exclusividad real desde el sentinel artificial; la reserva y pruebas de proveedor siguen pendientes. Los mounts y ACL se prueban con secretos ficticios. La verificación de permisos real exige asignación/namespace compatibles; la disposición histórica de TLS 10001/0700/0400 no se convierte automáticamente.
- Ledger y rollback: autorización consumida antes de mutar, lock/journal/retención, rollback solamente a target previo healthy; parada ante unknown. La recuperación de operación fallida requiere intervención separada, no hay rollback automático ni borrado de locks/SQL.
- Readiness API: endpoint local /ready=200 es contrato operativo existente, pero la fixture lo simula; no sustituye pruebas SQL/PG17/HTTP/Chromium reales de H6 y verificación productiva de identidad/bindings. Alerta ACK prueba correlación/recepción, no acredita todo incidente de observabilidad. Backup V2 postinstalación, SQL provider y custodia independientes son precondiciones externas, no se firman desde este informe.
- Preparación de host: SSH/22 compartido versus servicio dedicado, custodia nueve claves, identidad y vigencia de expedientes, TLS/SAN/CA, permisos, reserva de redes y puertos, capturas/restauración real antes/después de SQL, revisión externa obligatoria para deploy. No resolver estos puntos relajando una norma.
